## 4. 新发现缺陷（按影响排序）

### 高

| # | 缺陷 | 证据 | 影响 |
|---|---|---|---|
| H1 | **导出功能不可用**：`POST /dashboards/{id}/export` 使用 bucket `exports`，MinIO 中不存在该 bucket（实际声明的 bucket 是 `dba-export`），预签名签发失败 → 返回空 URL | 后端日志 `S3 operation failed; code: NoSuchBucket, resource: /exports` | 大屏导出（pdf/xlsx）实际拿不到下载地址 |
| H2 | **记忆指标接口异常降级**：`/obs/metrics/memory` 抛 `'float' object is not callable`，被降级为空值 | 后端日志连续 4 次 | 记忆命中率恒为 0，指标不可用 |
| H3 | **预算用量写入主键冲突**：`budget_usage` 出现 `Duplicate entry '1-2026-10-01' for key 'budget_usage.PRIMARY'` | 后端日志 3 次 | 预算用量并发写入失败，账本可能漏记 |

### 中

| # | 缺陷 | 证据 | 影响 |
|---|---|---|---|
| M1 | 总览「成功率」少乘 100：后端返回比值 `0.4928`，前端直接加 `%` → 显示 `0.4928%`（实际 34/69 = 49.28%） | `OverviewPage.tsx:19` + `/obs/overview` | 观测结论严重误读 |
| M2 | 异常列表「类型」列回落成严重度（`a.alert_type ?? a.severity`，接口无 `alert_type`） | `AnomaliesPage.tsx` | 两列信息重复，真实分类不可见 |
| M3 | 失败 Run 的 `error_code` 全为 NULL（69 条中 35 条非成功，`error_code` 取值集合为空） | `/obs/runs` 响应 | 无法从列表判断失败原因 |
| M4 | 拓扑页恒为空：`run_doc` 有完整 span，但 `/obs/topology` 返回空节点与空边 | `08-obs-topology.png` + 接口响应 | 差异化功能失效 |

### 设计内降级（非缺陷）

- 复用率曲线为空态：`skill_usage` 无生产写入方，接口返回 `"note":"无数据：需要按天的技能复用率与命中/未命中 token 明细"` —— 与设计一致。
- 观测 / FinOps 二级页无顶部导航入口，需直接输入 URL。
- 真模型下护栏拒绝难以从 UI 触发：模型会自我审查并改写查询，护栏仍然生效（审计表 44 条 deny 可证）。
- 前端 `/chat/sessions` 无 UI 入口：会话管理目前只能通过接口。

4. 建议优先修 H1（导出）、H2（记忆指标）、H3（预算用量冲突）与 M1（成功率显示），这四项直接影响业务可用性与结论可信度。
